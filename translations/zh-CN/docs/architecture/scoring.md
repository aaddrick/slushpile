这条流水线产出的每一个数字，都是对两个问题之一的回答：候选人在这个具体岗位的队列里排在
哪里，以及经由某个渠道投出的一份申请究竟值多少。这里没有任何东西会孤立地拿一份文档去对
一份招聘启事打分，因为那是一个真实的数字，回答的却是错的问题。

## 申请者池锚定

关键词匹配度是拿简历去比一份职位描述。没有人是被一份职位描述录用的。决定结果的那次比较，
是跟队列里其他申请者比，而匹配度看不见他们。

所以搜索阶段先估计申请者池：还有谁会投这个岗位，中位数、75 百分位和 90 百分位的申请者
长什么样。然后把候选人定位到这个分布里，**并把申请者池百分位记为规范的匹配度数字。**
关键词匹配度如果还要的话，放进一个单独的字段。把两者合并正是这套评分标准存在要防止的
那种失效。

| 申请者池位置 | 档位 | 含义 |
| --- | --- | --- |
| p75+ | Tier 1 | 高于这个具体岗位的「强申请者」门槛 |
| p55–p74 | Tier 2 | 有竞争力，但没有差异化。需要一个渠道优势。 |
| p35–p54 | Tier 3 | 低于中位数。只在有强渠道时才追。 |
| below p35 | Pass | 申请者池的水平压过候选人。冷投是一个浪费掉的名额。 |

各项输入是有次序的。两条或更多未满足的关键最低资格要求，会不顾其他一切把这个职位下调
一到两个档位。然后是申请者池比较：最强的那条声称在这里真的排得上号，还是其实就是中位数？
然后是与该岗位真实运转节奏的偏离，然后是各项风险因素，每项大约五到十个百分位点，
最后是这家公司的校准先验。

这个阶段最有用的产出，是一条被声称的差异化优势回来时被标成「申请者池中位数」。这是候选人
从文档扫描器那里拿不到的信息，而且它通常就是那个会改变他们写什么的东西。

## 按渠道条件化的判定

同一份材料，按送达方式不同，转化率天差地别。单一判定是在对这个差别取平均，然后把这个平均值
当作关于这份申请的事实报出来。

因此每个 Tier 1–3 的岗位拿到的是一个矩阵，而不是一个判定：

| 渠道 | 门槛 | 大致的过筛率区间 |
| --- | --- | --- |
| 冷投 | 无 | 5–15%，随申请者池位置浮动 |
| 温内推 | 必须存在一个内推人 | 25–50%，取决于申请者池 |
| 冷触达某位具名员工 | 一个可识别的目标 | 5–15% |
| 由公开作品带来的被动引流 | 一件已有的作品，且已铺垫过 | 若命中则 20–40% |
| 猎头主动联系 | 不在候选人控制范围内 | 不做估计 |

有两条规则让这张表不至于沦为装饰。

**该岗位的档位取*可用*渠道中的最高档**，并且矩阵会记下是哪个渠道解锁了它、必须过哪道门槛。
如果目前不存在内推人，温内推那一行就只是参考信息，并不解锁 Tier 1。靠一个用不上的渠道来
抬高档位，是这张矩阵被玩坏的最常见方式，而且是自己坑自己。

**用户自己的历史胜过任何先验。** 凡是 `job_search.md` 里记录了在这家公司的真实温内推转化率，
就用那个数字取代通用的那个。参见 [memory-and-calibration.md](memory-and-calibration.md)。

## 材料质量不是期望值

审阅把这两者报为两个独立的数字，因为它们经常互相不一致。极好的材料投给一个不合适的岗位，
期望值依然很低；尚可的材料经内推投给一个很合适的岗位，期望值很高。

把两者合并，会在诚实的建议本该是「拿那一小时去找个内推人」的时候，告诉用户再花一小时改稿。
一个 8/10 的材料分紧挨着 1–3% 的冷投转化率，不是矛盾，那就是全部结论本身。

## 淘汰条件

淘汰条件在扫描时运行，并对照 `preferences.yaml` 检查：薪酬、地点、涉密许可，以及用户记录为
约束的其他任何东西。

有两条性质比这份清单本身更重要。

**通过项也要说出来，不只是失败项。** 一项只报告失败内容的检查，和一项根本没跑的检查无法区分，
而这里没有解释器能证明它跑过。

**一次 Pass 要指名它唯一的主要阻断因素。** 如果没有哪一个阻断因素能独立地为放弃这个岗位
辩护，那这个岗位拿到的就是一个分数，而不是一次 Pass。由一堆小疑虑累积起来撑住的 Pass
是一种情绪，它撑不过用户一周后自己回头再读一遍。

薪酬是按**公示区间**评估的，用的是 `preferences.yaml` 里记录的计算方法。offer 阶段的条款
在这里被明确排除在外，理由和它们在审阅中被剔除的理由相同：参见
[the-review.md](the-review.md#the-gatekeeper)。

## 概率区间，而不是判定词

输出是「1–3% 进面试」，而不是「MAYBE」。一个区间自带它的不确定性，并且可以拿去对真实发生的
事做校验；一个判定词两样都没有，也校验不了。

这也正是校准循环之所以可能的原因。「MAYBE」没法对结果做回归。一个百分比可以，而
[memory-and-calibration.md](memory-and-calibration.md) 就是那场回归发生的地方。
